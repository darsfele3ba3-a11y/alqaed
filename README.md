# ألعاب اللغة العربية التفاعلية – القائد / محمود حسين

مشروع ألعاب تعليمية تفاعلية لمنهج اللغة العربية (الفصل الدراسي الأول) للصفوف:
الأول والثاني والثالث الإعدادي.

- **108 درسًا** (36 لكل صف)، ولكل درس صفحة مستقلة بها 5 ألعاب:
  اختيار من متعدد – الفقاعات المتساقطة – التنشين والاصطياد – صح أم خطأ – تحدي العباقرة.
- إرسال النتيجة للمعلم عبر واتساب: 01022899556

## هيكل الملفات
```
index.html            الصفحة الرئيسية (اختيار الصف)
assets/logo.jpg       الشعار
grade1/index.html     دروس الصف الأول الإعدادي
grade2/index.html     دروس الصف الثاني الإعدادي
grade3/index.html     دروس الصف الثالث الإعدادي
gradeN/uX-lY-*.html   صفحة كل درس
```

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub وارفع **محتويات** هذا المجلد كما هي (index.html في جذر المستودع).
2. من Settings ← Pages اختر الفرع `main` والمجلد `/ (root)` ثم Save.
3. بعد دقيقة سيعمل الموقع على الرابط: `https://USERNAME.github.io/REPO/`
